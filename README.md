# cloud-parking-spring

> Controlar ocupação de vagas, entrada/saída de veículos e cálculo de tarifas sem inconsistência de estado.

## Problema

Controlar ocupação de vagas, entrada/saída de veículos e cálculo de tarifas sem inconsistência de estado.

## Solução

Domínio em grid (A1, B2…) com check-in por placa+vaga e check-out com tarifa automática e liberação da vaga. API REST em Spring Boot, MySQL para persistência, Redis para cache e ambiente reproducível via Docker Compose.

## Stack

- Java
- Spring Boot
- REST API
- Docker
- MySQL
- Redis
